# Age Calculator

生年月日から現在の年齢を計算するシンプルな Web アプリです。  
GitHub Pages を利用して公開しています。

## 🔗 公開ページ
https://koki0620.github.io/age_calculator/

## 📁 フォルダ構成
```
age_calculator/
├─ index.html
├─ css/
│   └─ style.css
└─ js/
└─ main.js
```

## 🧮 機能
- 生年月日を入力すると年齢を計算
- 今日が誕生日を過ぎているかどうかを判定
- ブラウザだけで動作（JavaScript）

## 🚀 使用方法
1. 生年月日を入力
2. 「計算する」ボタンをクリック
3. 年齢が表示されます
